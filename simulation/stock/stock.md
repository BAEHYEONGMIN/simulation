시뮬레이션 목적 : 어느 주식의 시간별 가격 데이터를 이용하여, 과거 시점부터 시뮬레이션이 시작된다. 각 지점에서 유저는 보유한 현금과 주식을 이용하여 자유롭게 매수/매도 할 수 있다.

이는 시장의 뉴스나 기업의 실적에 입각한 투자가 아닌, 오롯이 차트 위주의 테크니컬 트레이딩을 연습하는 시뮬레이션이다. 데이터는 실제 데이터와, 가상의 데이터를 사용할 수 있다.

요구사항 : 
1. 커다란 격자 좌표 모양의 주식 그래프가 위치한 영역
2. 전체 자산 / 현금 / 주식 수와 주식의 가격을 보여주는 영역
3. 매수 / 매도 버튼과, 얼만큼 사고 팔지를 슬라이드로 지정하는 영역(0~100%로 나타내며 매 단계에서 항상 0으로 초기화 된다. 주식은 항상 정수 단위로만 판매할 수 있게한다. 매수/매도를 한다고 턴이 지나가지는 않으며, 거래 수수료는 있되 0으로 설정한다.)
4. 다음턴 이동 버튼 (모든 거래를 끝 마치고, 다음 시간대의 턴으로 이동한다. 이동시 그래프가 이어서 생기거나, 이미 화면에 꽉 차있을시 왼쪽으로 당겨지며 새로운 부분이 드러난다. 이때 2번 부분이 업데이트 되어야함)

5. 데이터는 추후에 수집할것이므로 대충 가상의 데이터를 넣되, 플러스 마이너스 30% 이내로 움직이도록 한다. 초기 가격은 100으로 시작.
